Using Buckeye Studio
  1. Click an element on the page. Select parent to edit a section or whole illustration.
  2. Use the floating drag handle to reposition it. Use the inspector for fonts, size, color, borders, lines, and spacing.
  3. Edit words and line breaks in the Text box, then Apply text. Do not change a whole form or container’s text.
  4. This screen only isolates text and styles. All screens changes the shared baseline; existing per-screen overrides still take priority.
  5. Interactive preview runs website scripts in an isolated frame with sample locations and fees. No real submissions or API calls are allowed. Use Form step to inspect pages on the editing canvas.
  6. Save draft keeps your project in the private editor. Download project is a portable backup. Export HTML downloads the live-ready page without publishing.
  7. Publishing requires your Cloudflare login, a connected GitHub token, and an explicit review confirmation.
