# Typography changes

The previous accumulated styles used several conflicting font sizes, desktop-first media queries, fixed text-box heights and per-element translations. The revised stylesheet replaces them with a single mobile-first cascade. Website wording, HTML structure, form fields, scripts, contact details and service availability are unchanged.

1. **Fluid headings:** `--h1`, `--h2`, `--h3`, `--step-title` and `--wizard-title` each use `clamp()`. Heading selectors consume those tokens consistently. No breakpoint sets a new heading font size. Artwork titles, monograms and process numerals also use `clamp()`. Line height and letter spacing remain proportional to the type.
2. **Unbroken critical lines:** Buttons, short taglines, brand labels, contact links and fee-total lines use `white-space: nowrap`. Their containing grids use `minmax(0, 1fr)`, children use `min-inline-size: 0`, and controls use modest padding with viewport-aware label sizes. Service cards remain one column until 701px so their longest link fits. Long instructions, descriptions, legal text, addresses and search results may wrap; making those nowrap would force overflow or illegibly small text. Existing authored `<br>` breaks remain intentional and are not overridden by nowrap.
3. **Artwork copy:** The desktop hero paragraph uses a fixed 28rem measure (448px at the default root size), a constant 1rem desktop font, and existing authored line breaks. It is capped at its available container width. Other paragraphs remain responsive. At browser zoom or larger user font settings, natural wrapping is allowed instead of clipping content.
4. **Captions:** Captions and compact labels use `min()`, for example `font-size: min(.8125rem, 4vw)`. Their normal font size is the cap; only very narrow screens reduce it. Mobile form inputs stay at 1rem for readability.
5. **Readable measures:** General paragraphs use `max-inline-size: 70ch`; service and intro paragraphs use shorter contextual measures. The overall page width is capped at 73.75rem (1180px at default root size).
6. **Mobile-first layout:** The base uses one-column layouts and a compact menu. Only `min-width` queries enhance layouts at 351px (responsive copy), 560px (action row), 701px (cards/forms), and 1025px (desktop navigation/hero/process/FAQ). A separate reduced-motion preference query is retained. No page-level overflow hiding masks layout errors.

The source stylesheet is `responsive.css`. The viewport review page exercises all five appointment steps plus sample progress labels and a long fee-total state. It checks document width, element bounds and unbroken-label overflow. These layout checks do not test production routing, email delivery, all possible user data, all browser engines, or every custom font/zoom configuration.
